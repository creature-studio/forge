v0.3.1 · 2026-11-16

内嵌 Terminal 与最大化。下载 v0.3.1

  • 新增轻量内嵌 Shell：按 F8 打开/隐藏，隐藏后会话保留。
  • 按 F11 最大化/还原 Terminal，Shell 不会重启；支持 PTY resize、命令输入和粘贴。
  • 改进文件预览滚动条：独立占用一列，避免遮挡代码；提高轨道对比度。

范围：单个本地 Shell，会话随 Forge 退出而结束，暂不支持 tmux 会话保持。

v0.3.0 · 2026-11-16

关注点导航与 Git 审查体验。GitHub 发布页与下载

  • Focus Overview：在三列宽的导航栏中标记搜索结果、已暂存/未暂存 Git 改动和视口，点击跳转；可从 Settings 开关。
  • 长文件改动位置概览与按需加载跳转；Git Change Peek 现在可在有界长文件中使用，新增暗红/暗绿整行差异样式。
  • 修复 Blame 点击行在重绘时失效的问题；保留行尾简短归属、底部完整信息与 F6 详情。
  • 优化空闲性能：减少重复后台 Git 检查，关闭 Overview 时不扫描整文件。

已知边界：Git Change Peek 目前是浮动覆盖面板，不会将后续代码向下挤开；Focus Overview 不绘制代码纹理。
