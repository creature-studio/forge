v0.3.3 · 2026-11-16

Terminal interaction, focus-aware hints and Git History. v0.3.3 release

  • Up to eight independent local PTY Shell tabs with clickable selection, close/new buttons, Alt+1–8 and F12 navigation.
  • Terminal scrollback, selection and copy, bracketed paste, and improved xterm mouse and keyboard handling.
  • Focus-sensitive footer guidance and dedicated Terminal help via F4 or the ? control.
  • Theme-aware Git History commit details with green additions/red deletions; expanding commit folders preserves the detail view.

Scope: Local PTY sessions only; no integrated tmux persistence.

v0.3.2 · 2026-11-16

Workspace switching and stability fixes. v0.3.2 release

  • Alt+O recent workspace switcher and improved Files/Git navigation.
  • Improvements to request cancellation, filesystem watcher notifications and embedded Terminal rendering.

v0.3.1 · 2026-11-16

Embedded Terminal and maximize/restore. Download v0.3.1

  • Lightweight embedded Shell: F8 shows/hides the panel without restarting the session.
  • F11 maximizes/restores the Terminal; supports PTY resize, keyboard input and paste.
  • Preview scrollbar now uses its own column, with a more visible track.

Scope: one local Shell session, closed when Forge exits; no tmux persistence yet.

v0.3.0 · 2026-11-16

Focus navigation and Git review. Release and downloads

  • Focus Overview: three-column clickable navigation for search hits, staged/unstaged changes and viewport position; configurable in Settings.
  • Whole-file Git markers for paged files, bounded long-file Git Change Peek, and calmer full-row red/green diff styling.
  • Fix clicked Blame attribution resetting on redraw; keep concise inline author, complete footer attribution and F6 details.
  • Reduce idle Git work and skip file-wide Overview scans when disabled.

Limitations: Git Change Peek is a floating overlay, not an inline insertion; the Overview ruler does not render miniature source code.

v0.2.0

Themes, code highlighting and commit workflow. Release and downloads

  • Theme presets and broader script/code syntax highlighting.
  • Improved commit composer and file/Git workflows.

Release history and installation

For the complete release history, platform-specific archives and checksum files, use GitHub Releases. The source-controlled CHANGELOG.md tracks changes.

Official archives target glibc Linux (x86_64/aarch64) and macOS (Intel/Apple Silicon). No native Windows release; WSL is an option.
