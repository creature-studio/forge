安装与启动

Forge 是文件管理与 Git 操作一体的终端程序。官方预编译包面向 Linux glibc（x86_64、aarch64）及 macOS（Intel、Apple Silicon）；Windows 建议使用 WSL 或从源码构建。

curl -fsSL https://creature-studio.github.io/forge/install.sh | sh
forge

在任意项目目录执行 forge，不会要求必须是 Git 仓库。使用 forge update --check 查看新版本，forge update 升级。

文件管理与搜索

F1 打开文件视图，左侧文件树支持展开、收起、文件操作和滚动；右侧用于预览或编辑。使用 Ctrl-P 搜索文件，Ctrl-F 在当前文件内搜索。文件内容会按需加载，长文件不必一次加载全部内容。

鼠标可选择、复制和滚动，也能通过右键菜单执行文件操作。源码预览支持语法高亮、自动换行和 Markdown 预览；F3 可切换 Markdown 源码与渲染内容。

Git Diff 与提交

F2 进入 Git 视图。检查已暂存与未暂存修改，可对文件、目录、Hunk 和行进行暂存或取消暂存。Diff 支持完整文件浏览，不仅是上下文块。

Git 视图中 s 暂存、u 取消暂存、c 打开提交编辑器。分支与 Stash 可通过 B、Z 进入；历史视图也支持键盘操作。

关注点导航与改动预览

右侧 Focus Overview 只展示搜索命中、Git 改动与当前视口位置，并不是代码缩略图。点击导航栏的标记会跳到目标行，长文件会按需继续加载。可在 Settings 中关闭。

点击行号旁的 Git 变更标记，或按 F7 打开 Git Change Peek，查看红绿新增/删除行；按 Esc 关闭。Peek 当前是覆盖式面板，不会将下方代码向下推开。

Blame 与提交详情

点击一行源码后，Forge 会在可用空间内显示作者与相对时间，并在底部给出完整归属信息。F6 可以查看提交详情。长代码行没有空白时，不会覆盖代码；格式化 Markdown 请先切换到源码模式。

设置与常用快捷键

通过 , 打开 Settings，F4 打开快捷键管理，: 或 Ctrl-K 进入命令面板；? 打开帮助。Focus Overview、自动换行及 Git 显示选项都可以根据终端宽度调整。

完整键位与实现边界可参考 操作参考 和 快捷键说明。
