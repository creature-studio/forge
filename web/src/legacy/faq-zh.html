Forge 与 lazygit、ranger 这类终端工具有什么区别？

lazygit 更专注 Git 操作，ranger 更专注文件浏览；Forge 把文件树、代码预览、Git Diff 和暂存提交放进同一个 TUI 工作区。它不是要替代完整编辑器或 Git 命令，而是减少文件与 Git 工具之间的切换。可阅读 英文使用指南 查看详细操作流程。

Forge 是什么？

Forge 是一个运行在终端里的 Git 工作台和文件管理器。它把文件树、文件预览、并排 Diff、暂存、提交、历史、分支、Stash、Worktree 和搜索放进同一个 TUI 界面，使用 Rust 构建。

Forge 和普通 Git 命令行有什么区别？

Forge 不替代 Git，而是在 Git 之上提供一个持续可见的工作区。你仍然使用熟悉的 Git 语义，但可以在一个界面里浏览文件、查看并排 Diff、按文件或 Hunk 暂存、审阅历史并完成远程同步。

运行 Forge 需要什么环境？

需要 Git，以及一个支持 ANSI 颜色、鼠标和剪贴板的终端。官方为 Linux（x86_64 / arm64 glibc）、macOS（Intel / Apple Silicon）和原生 Windows 10/11 x64 提供预编译二进制，不需要 Rust 工具链。Windows 无需 WSL；Git 操作需要另行安装 Git。

怎么安装和升级 Forge？

Linux 和 macOS 可运行 curl -fsSL https://forge.runs-on.dev/install.sh | sh 安装，使用 forge update --check 检查更新、forge update 升级。Windows x64 可在 PowerShell 运行 irm https://forge.runs-on.dev/install.txt | iex；升级时关闭 Forge 后重新运行安装脚本。安装器会校验发布包的 SHA-256。也可以先查看 GitHub 上的安装脚本或手动下载发布包。

需要安装 Nerd Font 吗？

不需要。Forge 默认使用内置 Unicode 图标；也可以通过 FORGE_ICONS=nerd 启用 Nerd Font 图标，或使用 FORGE_ICONS=ascii 切换到 ASCII。

支持哪些语言的语法高亮？

内置 23 种语言：Python、TypeScript、JavaScript、Go、C/C++、Java、C#、Ruby、PHP、Lua、Kotlin、Swift、Shell、SQL、JSON、YAML、TOML、HTML、CSS、XML、Dockerfile、PowerShell，以及原生渲染的 Rust 与 Markdown。把 Sublime 的 .sublime-syntax 放进 ~/.config/forge/syntaxes/ 还能扩展或覆盖。

可以换配色主题吗？

可以。设置里提供 current、VS Code Dark、VS Code Black、GitHub Dark 和 Nord 五套主题，选中即时生效，并写入 ~/.config/forge/config.toml 的 theme 键。

Forge 会自动修改或覆盖我的仓库吗？

Forge 的写操作都有明确边界。Stage 和 Unstage 不会丢弃工作区编辑；Discard 和 Delete 需要单独确认；不会自动提交合并结果，也不会强制覆盖远程历史。
