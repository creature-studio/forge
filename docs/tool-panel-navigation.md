# 工具面板导航与上下文一致性

这一轮只统一现有交互，不改变 Git / 文件写入语义。终端鼠标与键盘在同一个工具列表里遵循一致焦点规则。

## 操作约定

| 输入 | 行为 |
| --- | --- |
| 方向键、j/k（非输入面板） | 移动列表选中 |
| PageUp / PageDown | 按列表可视高度移动选中行 |
| Home / End（非输入面板） | 选择首尾行；在搜索输入框内仍移动文字光标 |
| Ctrl+PageUp / Ctrl+PageDown | 滚动详情/上下文预览，不改列表选中 |
| 鼠标滚轮位于列表 | 只滚动列表视口，不改选中行 |
| 鼠标滚轮位于详情 | 只滚动详情，不改选中行 |
| 单击列表行 | 选中 |
| 450 毫秒内双击同一项 | 执行 Enter 打开；写入 Git 仍需原有确认 |
| Esc | 返回父面板；最顶层关闭工具 |
| 在工具面板按冒号 | 打开 Commands 子页，Esc 返回原列表 |
| 工具面板按 F4 | 打开快捷键界面，Esc 回原面板 |

滚动偏移和选中行是独立状态。查询结果排序、刷新或键盘滚动后，过期的鼠标双击状态会失效，避免选中错误对象。

## 上下文行为

- Branches 默认高亮当前检出的分支；对当前分支 Enter 保持无操作。
- History 固定版本（Space）→ 比较（D）→ Esc 回到 History，保留固定版本。
- Branches 或其他工具列表的 Commands 子页，Esc 返回原工具列表并保留选中。
- 文件搜索与内容搜索分别记住上一查询，内容搜索还记住 Regex 开关。状态仅当前进程有效，按 Worktree 独立存储。用户可用退格等编辑按键清空草稿。
- 非 Git 目录的命令面板不列 Git-only 命令；无结果时说明 Git 命令需要仓库。
- Stash 操作提示转至可滚动的详情文本，标题只写 Stashes，在窄终端中仍能读到常见操作。

## 测试证据

真实 PTY/tmux 回归脚本：scripts/smoke-tool-navigation.py。
测试使用 45 个分支和 57 个文件，覆盖分页、双击确认、上下文/详情滚动、搜索草稿保留、历史栈、F4、窄屏和非 Git 命令过滤。

单元测试验证独立的 list_offset/detail scroll、按键、鼠标命中、双击安全确认、跨 Worktree 搜索状态隔离及命令过滤。

所有 Git 写入测试使用临时仓库，没有推送真实项目。
