# Forge 使用体验与 Settings 建议

建议增加轻量 Settings 弹窗，先把已经存在的偏好集中起来并持久化。下一轮优先补外部改动自动刷新，再改善侧栏宽度和操作反馈。

本次依据当前源码评估。仓库中的截图早于现有 Files / Git 标签等功能，未将旧截图当作当前界面。以下是产品建议，尚未实现或进行本轮终端交互验证。

现在已经有文件搜索、内容搜索、过滤、多选、内置编辑器、文件及单行暂存、历史对比、分支、Stash、冲突处理、远程同步和 Worktree。现阶段继续增加 Git 功能的收益，预计低于把配置、刷新和操作入口打磨完整。

Settings 值得做的直接依据：

| 当前情况 | 对使用的影响 | 代码依据 |
| --- | --- | --- |
| `Config` 只有 `theme` 占位字段，加载只返回默认值；应用把结果放进 `_config` | 偏好没有实际加载、保存和应用链路 | [配置模块](../crates/forge-config/src/lib.rs#L8)、[工作区初始化](../crates/forge-app/src/lib.rs#L339) |
| 颜色依赖启动参数或 `FORGE_COLOR`；图标依赖 `FORGE_ICONS` | 用户需记住参数，终端适配选项不容易发现 | [CLI](../crates/forge/src/main.rs)、[颜色初始化](../crates/forge-app/src/lib.rs#L197)、[图标模块](../crates/forge-ui/src/icons.rs) |
| 隐藏文件和排除目录已有过滤入口，外部编辑器读取 `$EDITOR` / `$VISUAL` | 能调整当前行为，但缺少统一的默认偏好管理 | [文件过滤](../crates/forge-app/src/tools.rs#L607)、[外部编辑器](../crates/forge-app/src/tools.rs#L208) |

第一版 Settings 建议这样收敛：

| 分组 | 设置项 | 第一版范围 |
| --- | --- | --- |
| 外观 | 颜色模式、图标模式 | 暴露现有 16 色 / 256 色 / Truecolor，以及 Builtin / Nerd Font / ASCII；支持预览 |
| 文件 | 默认显示隐藏文件、默认排除目录 | 复用现有过滤能力，保存下次启动的默认值 |
| 编辑器 | 外部编辑器命令 | 允许显式配置；未配置时沿用 `$EDITOR` → `$VISUAL` → `vi` |
| 信息 | 配置路径、当前生效值及来源 | 让用户能判断设置来自配置文件、环境变量还是启动参数 |

交互沿用现有弹窗形式：在 `:` 命令面板加入 Settings，可补充当前未占用的 `,` 快捷键。支持键盘导航、滚动、`Ctrl-S` 保存和 `Esc` 取消；颜色和图标预览在取消时恢复。窄窗口仍可滚动访问全部设置项。

先实现用户级配置，Linux 可放在 `$XDG_CONFIG_HOME/forge/config.toml`，未设置时使用 `~/.config/forge/config.toml`。颜色、图标建议明确采用“启动参数 → `FORGE_*` 环境变量 → 配置文件 → 默认值”的优先级；被覆盖的选项需标明当前生效来源，避免出现保存成功但界面没变化的困惑。

保存采用原子替换，失败时保留编辑内容并显示原因；配置不存在时正常使用默认值，配置损坏时给出可定位的提示。恢复默认值也应经过明确保存。第一版保存隐藏文件、排除目录这类偏好；“仅看修改文件”、搜索词、多选项继续作为本次会话状态。

其他改进按以下顺序安排：

| 优先级 | 改进 | 具体场景与建议 |
| --- | --- | --- |
| 高 | 外部改动自动刷新 | 在另一个终端修改文件或执行 Git 后，当前界面应自动更新。现有后台循环处理的是应用任务完成通知，另有 `r` 手动刷新；未见文件监听链路。可加入事件合并和节流，刷新后保留选中路径、目录展开和滚动位置。 |
| 中 | 侧栏宽度调整 | 目前双栏时侧栏固定为窗口宽度的约四分之一，并限制在 24–40 列。长文件名和中文路径需要更宽空间，可增加调整命令，再补鼠标拖拽并记住用户宽度。 |
| 中 | 命令面板的可用性提示 | 已有 Files / Git 隔离和上下文快捷提示。继续让需要仓库、文件或特定 Git 状态的命令显示不可用原因，并为 Settings、刷新、帮助提供统一搜索入口。 |
| 中 | 统一操作记录 | 已有状态栏错误保留和最近远程操作结果，可进一步汇总文件操作、Stage、Commit、Push / Pull 的时间、对象、结果和错误详情，方便回看刚才发生了什么。第一版保留本次会话记录即可。 |
| 后续 | 打开目录与最近工作区 | 目前启动使用当前目录，也能切换 Worktree。可以再加入任意目录打开、最近工作区和可选的 `forge <path>`，减少退出后重新 `cd` 的操作。 |

上述判断对应 [任务完成通知](../crates/forge-app/src/view.rs#L47)、[手动刷新](../crates/forge-app/src/lib.rs#L1990)、[侧栏宽度](../crates/forge-app/src/view.rs#L145)、[命令过滤](../crates/forge-app/src/tools.rs#L740)、[状态栏](../crates/forge-app/src/view.rs#L863) 和 [启动目录](../crates/forge-app/src/lib.rs#L332)。

实施顺序建议：先完成配置加载与保存，再接 Settings 弹窗；随后补自动刷新，再做侧栏调整和操作记录。暂缓多主题市场、完整快捷键编辑器和多层项目配置，等实际使用需求明确后扩展。

Settings 完成时应验证：保存后重启生效、预览取消恢复原值、环境变量和启动参数覆盖关系明确、损坏配置可恢复、保存失败保留草稿，以及中文路径与窄窗口操作。自动刷新另需验证外部新增、删除和 Git 状态变化不会跳走当前选择。
