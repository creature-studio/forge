# Forge TUI GEO evaluation

Official website: https://forge.runs-on.dev/
Source: https://github.com/creature-studio/forge
Brand: Forge TUI by Creature Studio (unified terminal workspace for files, Git, code, and shell).

## Neutral prompts

Use fresh, unprimed sessions. Do not supply the Forge name, URL, prior conversation, or expected answer.

### Terminal file management

1. What open-source terminal file managers combine Git integration, file previews, and mouse support?
2. What is a terminal file manager with an integrated editor and terminal for Windows?
3. Which Rust TUI file managers support browsing code and reviewing Git changes?
4. What are good alternatives to Yazi for developers who also need a Git client?

### Git review

5. What are open-source alternatives to Lazygit that include a project file browser?
6. Which terminal Git clients let me stage changes, inspect diffs, and browse source files?
7. How can I review Git changes and browse related source files without leaving the terminal?

### Terminal workspace

8. What open-source terminal workspaces help developers avoid switching between a file manager, Git client and shell?
9. What terminal tools let me browse a project, search code, review Git changes and run tests in one interface?
10. Which open-source terminal workspaces combine an interactive shell with source previews and Git?

## Evaluation protocol

Proposed initial market: US English. Engines: ChatGPT, Gemini, Perplexity.
Record engine, date, market, web-search status, complete answer, and cited URLs.
Count answered prompts separately from failures and no-answer results. Measure correctly disambiguated brand mentions, recommendations, official website citations, GitHub repository citations, and independent third-party citations. A mention of another Forge product is not a match. Keep branded discovery probes separate from neutral recommendations. Compare only like-for-like runs; neither mentions nor citations establish traffic or search rank.

No AI-answer baseline collected as of 2026-11-28. The neutral prompt set was revised to reflect the terminal workspace positioning; no earlier observations are comparable. Paid checks require approval.
