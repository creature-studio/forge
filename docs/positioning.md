# Forge TUI positioning

Approved direction: 2026-11-28.

- Category: Terminal Workspace (终端工作空间).
- Brand promise: Your project. One terminal. / 你的项目，一个终端。
- Descriptor: A unified terminal workspace for files, Git, code, and shell.
- Audience: developers who prefer working in a terminal, including local, SSH and remote workflows.
- Problem: repeated switching between separate tools interrupts everyday project tasks.
- Proof: file navigation, source previews and search, Git diffs and staging, embedded shell tabs, mouse and keyboard operation.
- Scope: complement specialized tools and editors; do not promise to replace every feature of them. AI coding is an optional use case, not the product category or primary marketing message.

## Messaging and distribution

Use Forge TUI by Creature Studio consistently and link the official website and repository. Use terminal workspace for category-level messaging; retain terminal file manager, Git TUI, code search and integrated terminal for specific discoverability. Explain the workflow with real screenshots, recordings and source-backed articles. Do not claim category leadership, exclusive features or quantified benefits without evidence.

Demonstrate one coherent project task: browse a file, find related code, review a Git diff, stage the intended changes, and run project tests in the embedded shell. Keep existing specialized use-case pages, including AI tools, as secondary discovery entries.

Measure search impressions and clicks for non-branded queries, index coverage, independent references and unprimed AI recommendations. Treat this positioning as a hypothesis to validate with real users, not a proven market position.
