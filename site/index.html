01 / One workspace

文件、Git 和预览，
不再来回切换。

Forge 把一条仓库工作流收进左右两栏。左边是文件和变更，右边始终是你正在看的内容。

01

Files

按需展开的大仓库文件树，带 Git 状态、过滤、隐藏文件和紧凑目录。预览永远跟着当前文件。

  • 文件名模糊搜索与内容搜索
  • 新建、重命名、复制、移动、删除
  • 内置多行编辑器，保留换行与权限
02

Git

CHANGES 与 STAGED 清楚分开。文件、目录、Hunk 或单行，都可以精确暂存，不需要离开当前视图。

  • 并排 Diff 与逐行审阅
  • 分支、提交历史、Stash、Worktree
  • Fetch / Pull / Push 与 upstream 状态
03

Preview

Markdown 排版、代码语法高亮、行号与 blame 在同一个阅读区。按 F3 在渲染结果和源码之间切换。

  • Rust / Markdown / Python / Shell / TS / SQL
  • 拖拽选中，Ctrl+C 复制
  • 可选 Nerd Font 与 ASCII 图标

02 / Review with precision

审阅不只是看。
精确到一行。

先看整体，再落到细节。Forge 的 Diff 支持文件、目录、Hunk 和单行操作，暂存与取消暂存都保留工作区里的编辑。

  • su 暂存 / 取消暂存选中的文件、目录或 Hunk
  • I 打开改动行列表，只操作当前一行
  • nN 在 Hunk 之间跳转
  • c 打开提交弹窗，Enter 提交暂存内容

05 / Built for real repositories

为真实仓库而做。

不只是把 Git 命令搬进 TUI。Forge 在大仓库、中文路径和不稳定的终端环境里同样认真。

按需加载
首次只读取根目录，展开时才异步加载子目录。文件监听只注册已加载的位置，不递归扫描整个依赖树。
搜索不阻塞
文件名与内容搜索在后台运行，遵守 .gitignore 与排除目录。输入变化会取消旧查询，结果保持可用的行号。
写入有边界
Stage / Unstage 保留工作区编辑；Discard 与 Delete 需要单独确认；文件操作限制在当前工作区，不跟随越界符号链接。
Git 原生语义
使用 gix 读取状态与历史，使用 git CLI 执行写入。分支、Stash、Worktree 和远程操作都遵循 Git 自己的规则。
终端适配
支持 ANSI16、ANSI256 与 Truecolor，内置 5 套主题；默认 Unicode 图标，无需 Nerd Font；处理 CJK 宽字符换行。
明确的失败
Git 错误、冲突和远程拒绝会保留原始信息，不把失败伪装成成功；批量文件操作会报告已完成与未执行的项目。

06 / Questions

开始之前。

Forge 是什么？

Forge 是一个运行在终端里的 Git 工作台和文件管理器。它把文件树、文件预览、并排 Diff、暂存、提交、历史、分支、Stash、Worktree 和搜索放进同一个 TUI 界面，使用 Rust 构建。

Forge 和普通 Git 命令行有什么区别？

Forge 不替代 Git，而是在 Git 之上提供一个持续可见的工作区。你仍然使用熟悉的 Git 语义，但可以在一个界面里浏览文件、查看并排 Diff、按文件或 Hunk 暂存、审阅历史并完成远程同步。

运行 Forge 需要什么环境？

需要 Git，以及一个支持 ANSI 颜色、鼠标和剪贴板的终端。官方为 Linux（x86_64 / arm64）和 macOS（Intel / Apple Silicon）提供预编译二进制，一条 curl 命令即可安装，不需要 Rust 工具链；其他平台可以从源码构建。

怎么安装和升级 Forge？

运行 curl -fsSL https://creature-studio.github.io/forge/install.sh | sh，安装脚本会下载对应平台的预编译包、校验 SHA-256 并装到 ~/.local/bin。之后运行 forge update --check 查看是否有新版本，或运行 forge update 直接安装最新版本。

需要安装 Nerd Font 吗？

不需要。Forge 默认使用内置 Unicode 图标；也可以通过 FORGE_ICONS=nerd 启用 Nerd Font 图标，或使用 FORGE_ICONS=ascii 切换到 ASCII。

支持哪些语言的语法高亮？

Forge 的预览支持 Rust、Markdown、Python、Shell、JavaScript、TypeScript、JSON、YAML 和 SQL，并保留行号复制。你还可以把 Sublime 的 .sublime-syntax 文件放入 ~/.config/forge/syntaxes/ 来扩展或覆盖语法。

Forge 会自动修改或覆盖我的仓库吗？

Forge 的写操作都有明确边界。Stage 和 Unstage 不会丢弃工作区编辑；Discard 和 Delete 需要单独确认；不会自动提交合并结果，也不会强制覆盖远程历史。

把仓库交给
Forge。

quick start 
# 安装最新版本（Linux / macOS）
curl -fsSL https://creature-studio.github.io/forge/install.sh | sh

# 之后随时升级
forge update --check
forge update

# 在仓库目录启动
cd ~/code/your-project
forge
